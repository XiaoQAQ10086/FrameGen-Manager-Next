# 2026-11-22 运行时性能基线与复测

## 方法

- 机器：Windows，12 逻辑处理器；Electron 45.4.1，Rust release 原生插件。
- 数据：真实 9 游戏库，6 个封面缓存（0.3 MB）；每次运行复制到独立临时 `FGM_DATA_DIR`，不改用户数据。
- 内存：启动后 10 秒、60 秒各采样一次进程树（main / GPU / renderer / network utility）；报告 60 秒工作集（WS）与私有提交（Private）。共 5 次独立运行取中位数。
- 启动/切页：`FGM_PERF=1` + `FGM_PERF_NAV=1`，由 `renderer/perf.js` 记录 renderer 与主进程时间点；页面切换由 `page-ready`（数据渲染完成）计算。
- CPU：10–60 秒窗口内所有进程的累计 CPU 时间差，按 12 核换算。
- 原始日志：`docs/perf/after-2026-11-22.jsonl`。

内存预算：工作集 ≤350 MB、私有 ≤260 MB，均以 5 次中位数判断。工作集已贴近 Electron 45 的固定成本；继续下降需要关闭硬件加速或替换 UI 栈，已在决策中否决。

## 被否决的实验

| 实验 | 结果 | 结论 |
|---|---|---|
| `--disable-gpu` | WS 337 MB，私有 149 MB，但软件渲染 | 用户选择保留硬件加速 |
| `--in-process-gpu` | WS 332 MB，私有 348 MB | 私有内存反而更高 |
| `--disable-gpu-compositing` | WS 392 MB，空闲 CPU 0.90% | 明显变差 |
| `--max-old-space-size=64` | WS 355 MB，私有 263 MB | 无收益 |
| `--max-semi-space-size=2` | WS 356 MB，私有 255 MB | 噪声内，未采用 |
| Electron `nativeImage` 300×450 封面缩略图 | WS 360–368 MB | 主进程保留图片缓存，回退 |
| 保留硬件加速 + 毛玻璃/无限动画 | 切页和软件光栅成本高 | 已移除 |

最终采用 `--max-semi-space-size=8`、关闭 WebGL 与拼写检查；中位数工作集从约 354 MB 降到 348 MB。
