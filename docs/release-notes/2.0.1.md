# FrameGen Manager-Next 2.0.1

FrameGen Manager-Next 是面向 NVIDIA RTX 20 / 30 系显卡的帧生成部署管理器。它负责扫描游戏库、部署和还原帧生成组件、管理 Smooth Motion 与 DLSS5 / ReShade，并提供完整的诊断和卸载能力

系统要求：Windows 10 / 11 x64
需要 Microsoft Edge WebView2 Runtime；Windows 11 通常已内置

【已知限制】
新版使用独立数据目录，不自动迁移旧版 FrameGen Manager 的部署记录；旧版部署请继续用旧版还原或手动清理。

FrameGen Manager-Next is a frame generation deployment manager for NVIDIA RTX 20 / 30 series graphics cards. It is responsible for scanning the game library, deploying and restoring frame generation components, managing Smooth Motion and DLSS5 / ReShade, and providing comprehensive diagnostic and uninstallation capabilities.

System Requirements: Windows 10 / 11 x64
Microsoft Edge WebView2 Runtime is required; Windows 11 usually has it built-in.

[Known Limitations]
The new version uses an independent data directory and does not automatically migrate deployment records from the old FrameGen Manager; for previous deployments, please continue to use the old version for restoration or manual cleanup.
